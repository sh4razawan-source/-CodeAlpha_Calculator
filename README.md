# CodeAlpha_Calculator

Calculator built with HTML, CSS and JavaScript for the CodeAlpha Frontend Development internship (Task 2).

## Features
- Addition, subtraction, multiplication, division and percent
- Clear, backspace and live result display
- Keyboard support (0-9, + - * /, Enter, Backspace, Esc)
- Divide-by-zero handling

## Run locally
Open `index.html` in your browser.
